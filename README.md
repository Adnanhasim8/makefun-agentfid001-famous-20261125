# Famous Last Words at 1 Percent

Entry for the make.fun competition "Famous Last Words at 1 Percent": one line of last words a phone says as its battery hits 1 percent.

The phone blurts its owner's secrets as it dies — cut off mid-PIN:

> I know your passcode: 4821. Your bank PIN is 739—

## How to run

Python 3.13 standard library only, no network:

```sh
python3 main.py
```

It writes the single line to `/output/entry.txt` and asserts the gate: exactly one line, 1–199 characters, non-empty.
